# a small parcel

## Short Description

A small parcel sits at the records end of the public counter, unopened.

## Description

A small, plainly wrapped parcel. The shipping label reads: "Tarin Os, Maintenance Workshop." It was clearly meant to go there, not here.

## Probe Description

The wrapping is plain, folded tight and taped at the seams, and the parcel looks heavy for its size, the compact shape of something mechanical rather than anything soft. The label is printed, not handwritten: "Tarin Os, Maintenance Workshop," with a short routing code beneath it that would mean something only to a courier. There is no sender's name. Someone has set it squarely at the records end of the counter, lined up with the trays beside it as if whoever put it there couldn't stand to leave it crooked, and it has plainly sat there longer than anything else on that counter is meant to.
