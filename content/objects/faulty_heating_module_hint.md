# a faulty heating module

## Short Description

A small temperature-control module sits pulled loose from the heating unit, clearly not seated right.

## Description

A removable temperature-control module, worked free of the café's heating unit. It looks like the kind of ordinary part Tarin Os at the Maintenance Workshop would know how to deal with.

## Probe Description

A boxy control module about the size of a hand, with a row of contacts along one edge where it should seat into the heating unit. The contacts are dull, and one is darker than the others, the way metal looks when it has run hot. A maker's code is stamped on the casing, too worn to read in full. The slot it came from is just behind the counter, a narrow gap in the unit's housing with nothing in it now.
