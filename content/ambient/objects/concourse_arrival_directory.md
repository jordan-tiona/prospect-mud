# Arrival directory

## Short Description

An arrival directory stands near the lift doors, listing destinations in the Old Quarter.

## Description

A durable directory panel identifies Old Quarter Square as the way into the neighborhood. Below it are listings for the Corner Café, Maintenance Workshop, Residential Courtyard, and Civic Office, all reached from the square. The panel is scuffed at hand height from frequent use.

## Probe Description

The panel is a single sealed sheet, built to be wiped down rather than updated often. Old Quarter Square is set largest at the top, and the four listings beneath it are in smaller type, the Corner Café, the Maintenance Workshop, the Residential Courtyard and the Civic Office, each with a line about what someone would go there for. The surface is dulled to a haze at hand height where years of fingers have traced the same few routes. One corner of the panel has been replaced and doesn't quite match the rest, a shade brighter than the older material around it.
