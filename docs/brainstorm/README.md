# Brainstorm notes

**Not canon.** Nothing in this folder is Established, Provisional or even Draft. These are worldbuilding sessions between the project owner and the Lore lane, kept so ideas aren't lost.

- Never exported, never loaded into a prompt, never cited as a source by code, tests or content.
- An idea moves to canon only when the owner works through it in a later session and it's written into `docs/bible/` or `content/` through the normal approval process (CLAUDE.md, "Lore approval").
- Ideas here may contradict the bible. That's expected: the bible wins until the owner decides otherwise.

One file per topic. Each file records the date of each session, what the owner leaned towards, what is still open, and the options that were set aside.
